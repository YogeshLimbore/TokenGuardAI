# Contributing to TokenGuard AI

Thanks for helping improve TokenGuard AI. This guide covers the day-to-day
development workflow.

## Prerequisites

- Python **3.13+**
- [`uv`](https://docs.astral.sh/uv/)
- Docker + Docker Compose (for Postgres, Redis, and the full stack)
- Git

## Setup

```bash
cp .env.example .env
# fill secrets: JWT_SECRET_KEY, TOKEN_GUARD_MASTER_KEY, provider keys, etc.

uv sync --group dev
docker compose up -d postgres redis
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
```

Bootstrap the first platform admin (then remove `BOOTSTRAP_ADMIN_PASSWORD`
from `.env`):

```bash
# set BOOTSTRAP_ADMIN_EMAIL and BOOTSTRAP_ADMIN_PASSWORD in .env first
uv run python scripts/bootstrap_admin.py
```

## Tests

```bash
# full suite
uv run pytest -q

# unit / API only (exclude integration marker if you want)
uv run pytest -q -m "not load"

# integration flows
uv run pytest -q -m integration
```

Markers (see `pyproject.toml`):

| Marker        | Meaning                                      |
|---------------|----------------------------------------------|
| `integration` | Multi-step JWT / org / project API flows     |
| `load`        | Locust scenarios (run manually, not in CI)   |

## Load testing

```bash
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
uv run locust -f tests/load/locustfile.py --host http://127.0.0.1:8000 \
  --users 20 --spawn-rate 5 --run-time 2m --headless
```

See `docs/performance.md` for baseline targets.

## Lint and format

```bash
uv run ruff check app tests scripts
uv run ruff format app tests scripts
```

## Database migrations

```bash
uv run alembic revision --autogenerate -m "describe your change"
uv run alembic upgrade head
```

Review autogenerated migrations carefully before committing.

## Pull request checklist

- [ ] Tests added or updated for the behavior change
- [ ] `uv run pytest -q` passes locally
- [ ] No secrets committed (`.env`, keys, tokens)
- [ ] Migrations reviewed if models changed
- [ ] Docs / CHANGELOG updated for user-visible changes
- [ ] CI green

## Project layout (high level)

```
app/
  api/            # FastAPI routers
  core/           # Settings
  database/       # SQLAlchemy models + connection
  dependencies/   # AuthZ / AuthN dependencies
  middleware/     # Correlation ID, metrics, security headers
  observability/  # Logging, tracing, Prometheus
  security/       # RBAC permissions
  services/       # Business logic
  workers/        # Celery tasks
tests/            # Pytest suite (+ integration/, load/)
docs/             # Architecture, deployment, operations
```

## Code style

- Prefer clear, explicit FastAPI dependencies for auth and permissions.
- Never log passwords, JWTs, refresh tokens, or provider secrets.
- Prefer permission checks (`Permission.*`) over raw role string comparisons.
- Keep organization-scoped lookups filtered by `organization_id`.
